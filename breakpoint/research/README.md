# Agenda exports

Put a fresh rendered export of the official agenda here as `agenda-rendered.json`, covering all four day/stage tabs of https://solana.com/breakpoint/schedule, then run `python3 scripts/import-agenda.py` and `python3 scripts/clean-seed.py` from `breakpoint/`.

The original research files from the first build (agenda export of 12 November 2026, event and source notes) are kept in the claude.ai project "Breakpoint Guide" under `onsolana-breakpoint/research/`.
