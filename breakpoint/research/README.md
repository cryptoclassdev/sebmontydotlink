# Agenda exports

Agenda exports read from all four day/stage tabs of https://solana.com/breakpoint/schedule in a real browser. Latest: `agenda-export-2026-11-17.json` (113 talks, 8 breaks, read 17 November 11:25 London); earlier: `agenda-export-2026-11-13.json`. Import with `python3 scripts/import-agenda.py research/<file>.json` then `python3 scripts/clean-seed.py`, from `breakpoint/`.

The original research files from the first build (agenda export of 12 November 2026, event and source notes) are kept in the claude.ai project "Breakpoint Guide" under `onsolana-breakpoint/research/`.
