# X profile pictures

Each file is the current profile picture of a verified X account listed in `data/x-accounts.json` or `data/x-accounts-pictures.json` (speakers: linked from the official speakers page; companies: linked from the company site or checked on the profile). They identify a speaker or company next to its own name. Downloaded once through twitterapi.io with `scripts/fetch-x-avatars.py` (400 x 400 from X), resized to 96 x 96 px WebP. `scripts/build.mjs` copies them to `public/breakpoint/avatars/`; the site never loads X image URLs.

Accounts without a file show initials. Profile pictures change: rerun the script with `--refresh <handle>` to update one.
