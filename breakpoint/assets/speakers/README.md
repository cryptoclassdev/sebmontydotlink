# Speaker photos (optional)

Talk recaps in Catch up show each speaker as initials. To show a photo instead, add it here as
`<speaker-id>.webp` (the speaker's `id` in `data/seed.json`, for example `alexandra-lang.webp`), then run
`npm run build` in `breakpoint/` and commit the result. The build copies the files to `/breakpoint/speakers/`
and the page uses them automatically. Square images of about 96 px are plenty.

Use photos you have the right to publish, such as ones the speaker or the organiser provided for this purpose.
